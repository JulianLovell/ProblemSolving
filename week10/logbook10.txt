Problem 4 - BlockEnemy
Design Ideas:
Since we need to disconnect all occupied towns by removing roads with the least effort, we can treat the problem as finding a minimum cut in a graph. First, we represent the roads and efforts as a weighted graph,
then we identify and remove the min set of edges that seperates the occupied towns. Then using Kruskals algorithm for a MST, we find the min effort required to disconnect the towns.
